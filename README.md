# 纸间 · Paper Room

面向折纸初学者的互动折纸原型。以 A4 纸开始，在可旋转的三维投影工作台上拖动、确认折叠、展开、沿折痕分段裁剪，再移动和回收纸片。

## 运行

不需要安装 JavaScript 依赖，也不请求外部素材或 API。可以直接用桌面浏览器打开 `dist/index.html`，或在此目录运行：

```sh
python3 -m http.server 8765 --directory dist
```

打开 http://localhost:8765 。Python 仅用作静态文件服务器，不是项目运行依赖；也可使用任何静态服务器。

## 操作

- 左键从纸面一点拖向目标：两点的中垂线成为折线，抓取一侧预览折起。
- 松开仅保留预览；空格/确认按钮提交为平折，Esc/取消清除预览。
- 右键拖动旋转视角，滚轮缩放；俯视/3D 视角按钮恢复常用视图。
- 可以在已折叠的形状上继续折叠。展开恢复材料坐标并保留折痕。
- 剪刀：先展开，再从折痕上拖出一段切口，空格确认。可分段继续剪；贯穿整张纸片后分离。
- 移动：拖动独立纸片，拖到回收站丢弃；点击回收站恢复最近一片。
- 撤销恢复上一步。选定纸型后点击「换一张新纸」。
- 纸张正反面与背景颜色可调整。

## 实现和限制

原生 HTML/CSS/JavaScript；Canvas 绘制三维坐标的正交投影。几何核心是多边形直线裁分、轴旋转预览、平折反射，以及材料坐标回映。无第三方运行库。

这是受约束的几何原型，不是真实纸张物理模拟。确认后完成 180° 平折；同一纸片折线一侧全部纸层一起折。没有柔性卷曲、自碰撞、单层抽取、压折/反向折和千纸鹤教程。观察视角可旋转和倾斜，但限制接近侧面的角度以保持拖动可用。深度排序在复杂交叠时可能不精确。裁剪仅支持展开状态和已有直线折痕；部分切口保存为切口标记，尚不模拟切口附近独立弯曲。只有贯穿纸片的直线切口会生成独立碎片，不支持多个转弯切口组合分离。教学是基础操作引导，不是完整折纸作品教程。刷新页面会重置，优先支持桌面鼠标和键盘。A4/A3 自动适配画布，实际尺寸由选项显示。

## 验证

几何测试验证了预览不修改折痕、连续两折面积守恒、撤销、展开、部分裁剪不分离、接续裁剪分离，以及 100 个不同方向的裁分面积守恒。另完成了桌面浏览器初始页面目视检查。完整鼠标操作链和不同设备仍需人工试用；自动化浏览器启动受当前环境限制。尚未进行课程要求的另一位真实用户试用。
